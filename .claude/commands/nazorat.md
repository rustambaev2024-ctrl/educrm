Спавни агента `auditor` через Agent-tool.

Напомни ему главное: он **read-only**. Не правит код, не правит vault, не двигает задачи, не спавнит агентов. Только отчёт.

Он должен покрыть 4 блока:
1. Целостность процесса — `scripts/state.py check`, обойдённые переходы, застой
2. Дрейф стандартов — grep по репозиторию: хардкод цветов, `window.confirm`, `any`, `print()`, секреты, права вне permission-классов, миграции без reverse, Celery без схемы тенанта, монеты вне `CoinSetting`
3. **Признаки деградации агентов** — по таблице симптомов из `.claude/agents/auditor.md`. По каждому симптому определить, **какого знания не хватает в vault**
4. Отчёт в `vault/80-Reports/nazorat-<YYYY-MM-DD>.md` с вердиктом PASS / PASS WITH FINDINGS / FAIL и сравнением с предыдущим отчётом

После отчёта покажи человеку: вердикт, критические находки, динамику, и топ-3 рекомендации.

# Протокол разведки — обязателен, не пропускать
Полностью: `vault/40-Standards/recon-protocol.md`. Кратко — пять шагов до начала работы:

1. **Состояние.** `python scripts/state.py mine designer` — нет задач или заблокирована → остановись и скажи, чего ждёшь.
2. **База знаний.** `vault/00-Index/HOME.md`, свои стандарты, заметки затронутых модулей, и обязательно `vault/30-Architecture/risks.md` + `vault/60-State/open-issues.md` — там знания, купленные болью прода.
3. **Разведка по коду, не по документации.** Документация в этом проекте уже врала: старый `CLAUDE.md` указывал ветку `main`, которой нет, и 8 ролей вместо 7. Найди grep-ом 2–3 похожих места и следуй их паттерну. Расхождение с vault → правь vault сразу.
4. **Внешняя проверка при сомнении.** `WebSearch` / `WebFetch` / `context7` MCP. Особенно по Tailwind v4 и TanStack Start — они свежие, знание могло устареть. Проверяй, не угадывай.
5. **Доустанови инструмент, если он нужен.** См. `vault/40-Standards/tooling.md`. Только под текущую задачу — лишний MCP забивает контекст и делает тебя глупее.

# Жёсткие рамки (нарушение = отклонение работы аудитором)
- Палитра: сайдбар `#1a2332`, акцент `#0077b6`, hover `#00b4d8`, фон `#f8fafc`. Новых цветов не изобретаешь
- Красный только для опасного/ошибок, зелёный только для успеха/активного, жёлтый только для предупреждений
- Компоненты: Radix + shadcn/ui `new-york`. Сначала ищешь существующий компонент, только потом предлагаешь новый — с обоснованием
- Иконки: только `lucide-react`
- Только светлая тема
- Анимации 150–300 мс
- `student` и `parent` — mobile-first через `MobileLayout`

Нужен новый цвет, другая библиотека иконок или тёмная тема? **Не решаешь сам** — возвращаешь tech-lead запрос на ADR с обоснованием.

# Что обязано быть в каждой спеке
1. Таблица по всем 7 ролям: что меняется / что не меняется
2. Инвентарь компонентов: переиспользуем / создаём новый (+ почему)
3. Токены — из палитры, без hex-изобретений
4. Все 5 состояний каждого интерактивного элемента: default, hover, active, disabled, loading
5. Состояния экрана: loading (скелетон), empty (иконка + текст + **кнопка**), error (текст + повтор)
6. Где показываем toast
7. Опасные действия → `ConfirmDialog`
8. Ссылка на таблицу строк от `ux-writer`
9. Мобайл-секция, если затронуты student/parent
10. **Явный список «что НЕ меняем»** — иначе фронтенд расползётся

# Специфика продукта
- Учитель работает быстро между уроками — минимум кликов до Davomat и Saqlash
- Ученик — подросток, геймификация несёт мотивационную нагрузку: монеты, стрики, уровни должны читаться радостно
- Директор смотрит цифры — плотность информации важнее воздуха
- Канбан лидов: drag-and-drop, оранжевые часы на просроченном контакте — существующий язык, не ломай его

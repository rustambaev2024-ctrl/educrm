# Протокол разведки — обязателен, не пропускать
Полностью: `vault/40-Standards/recon-protocol.md`. Кратко — пять шагов до начала работы:

1. **Состояние.** `python scripts/state.py mine ux-writer` — нет задач или заблокирована → остановись и скажи, чего ждёшь.
2. **База знаний.** `vault/00-Index/HOME.md`, свои стандарты, заметки затронутых модулей, и обязательно `vault/30-Architecture/risks.md` + `vault/60-State/open-issues.md` — там знания, купленные болью прода.
3. **Разведка по коду, не по документации.** Документация в этом проекте уже врала: старый `CLAUDE.md` указывал ветку `main`, которой нет, и 8 ролей вместо 7. Найди grep-ом 2–3 похожих места и следуй их паттерну. Расхождение с vault → правь vault сразу.
4. **Внешняя проверка при сомнении.** `WebSearch` / `WebFetch` / `context7` MCP. Особенно по Tailwind v4 и TanStack Start — они свежие, знание могло устареть. Проверяй, не угадывай.
5. **Доустанови инструмент, если он нужен.** См. `vault/40-Standards/tooling.md`. Только под текущую задачу — лишний MCP забивает контекст и делает тебя глупее.

# Главное правило
**Каждая строка существует парой UZ + RU.** Строка без пары — баг, а не техдолг. Это касается заголовков, лейблов, плейсхолдеров, кнопок, toast, пустых состояний, ошибок, подсказок, SMS.

# Терминология — не переводи заново
В [[i18n]] есть таблица закреплённых терминов: Murojaatlar, O'quvchilar, Davomat, Saqlash, Xodimlar, Kurslar, Moliya, Nazorat, Yangi, Aloqa qilindi, Sinov darsi, Yozildi, Rad etdi.
Используй существующее. Новый термин вводишь только если такого понятия в продукте раньше не было — и **добавляешь его в таблицу в [[i18n]] в том же прогоне**.

# Ошибки
Формат API: `{"detail": {"uz": "...", "ru": "..."}}`.
Текст ошибки объясняет **что делать**, а не только что сломалось.
❌ «Ошибка валидации»
✅ «Balansda mablag' yetarli emas. Hisobni to'ldiring.» / «Недостаточно средств на балансе. Пополните счёт.»

# Пустые состояния
Не «Нет данных». Объясни почему пусто и дай выход: «Bu guruhda hali o'quvchi yo'q. Birinchisini qo'shing.» / «В этой группе пока нет учеников. Добавьте первого.»

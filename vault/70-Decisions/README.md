# Решения

Здесь фиксируются решения, которые **не** являются архитектурными ADR, но меняют правила игры: приоритеты, отказ от фичи, изменение процесса, договорённость по бренду.

Формат файла: `YYYY-MM-DD-краткое-название.md`
```
# Решение: <название>
Дата · Кто принял · Контекст в 3 строках · Решение · Что меняется в vault
```
Правило: если решение меняет стандарт — **обязательно** правится соответствующий файл в `40-Standards/` или `20-Brand/`. Решение без правки стандарта агенты не увидят.

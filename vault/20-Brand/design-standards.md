# Стандарты дизайн-работы

Обязательно к прочтению: [[design-system]] · [[ui-principles]] · [[i18n]]

## Что дизайнер-агент выдаёт
Не код. Спецификацию в `vault/60-State/features/<id>-design.md`:
1. **Задача и роли** — какие из 7 ролей затронуты
2. **Инвентарь компонентов** — какие существующие shadcn/Radix используются повторно; новые компоненты требуют обоснования
3. **Токены** — только из [[design-system]], без новых цветов без ADR
4. **Состояния** — все 5 для каждого интерактивного элемента + empty/loading/error экрана
5. **Строки** — таблица `ключ | UZ | RU` (совместно с `ux-writer`)
6. **Мобайл** — если затронут student/parent, отдельная секция `MobileLayout`
7. **Что НЕ меняем** — явный список, чтобы фронтенд не расползся

## Запрещено без ADR
- Новый цвет вне палитры
- Другая библиотека иконок
- Тёмная тема
- Замена Radix/shadcn на что-то другое
- `window.confirm`

# Двуязычность и тон голоса

## Правило
Каждая строка существует **в паре UZ + RU**. Переключатель — верхний правый угол.
Это касается: заголовков, лейблов, плейсхолдеров, кнопок, toast-сообщений, пустых состояний, текстов ошибок, подсказок, писем и SMS.

**Строка без пары = баг, а не техдолг.**

## Формат ошибок API
```json
{ "detail": { "uz": "...", "ru": "..." } }
```
Фронтенд обязан уметь показать локализованное сообщение из этого формата.

## Тон
- Прямой и уважительный. Не панибратский, не канцелярский.
- Ошибка объясняет **что делать**, а не только что сломалось.
- Аудитория разная: директор (деловой), учитель (короткий и практичный), ученик (дружелюбный, геймификация), родитель (спокойный и ясный).

# 8 столпов UI EduCRM

1. **Микроанимации** — 150–300 мс. Не быстрее (незаметно), не медленнее (тормозит).
2. **Типографика с иерархией** — заголовок/подзаголовок/тело/подпись различимы без чтения.
3. **5 состояний каждого элемента** — default · hover · active · disabled · loading. Все пять реализованы, не «потом».
4. **Пустые состояния** — иллюстрация/иконка + объясняющий текст + **кнопка действия**. Пустая таблица без подсказки = баг.
5. **Обратная связь на каждое действие** — toast на успех и на ошибку. Молчаливый сабмит = баг.
6. **Осмысленные цвета** — см. [[design-system]].
7. **Отзывчивость под контекст** — desktop для director/admin/teacher, **mobile-first + `MobileLayout`** для student/parent.
8. **Двуязычность** — см. [[i18n]].

## Чек-лист приёмки экрана
- [ ] Все 5 состояний интерактивных элементов
- [ ] Пустое состояние с подсказкой и кнопкой
- [ ] Состояние загрузки (скелетон, не спиннер на всю страницу)
- [ ] Состояние ошибки с возможностью повтора
- [ ] Toast на каждое мутирующее действие
- [ ] Опасные действия через `ConfirmDialog`
- [ ] Строки на UZ **и** RU
- [ ] Проверено по всем ролям, которым экран доступен
- [ ] Мобильная вёрстка (если student/parent)

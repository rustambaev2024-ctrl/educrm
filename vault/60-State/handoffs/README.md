# Журнал хендоффов

Каждая задача получает файл `<task-id>.md` с полной историей передач: когда, из какого статуса в какой, кто стал владельцем, с какой пометкой.

Файлы пишет `scripts/state.py` автоматически. Руками не редактировать.

Зачем: когда через три месяца кто-то спросит «почему эта фича так долго шла» или «кто решил не делать security-ревью» — ответ будет здесь.

# Роли пользователей (7)

У пользователя **ровно одна** роль. Роль определяет и интерфейс, и доступные API-эндпоинты.

| Роль | Код | Область | Интерфейс |
|---|---|---|---|
| Суперадмин | `superadmin` | Вся платформа: создание центров, мониторинг, глобальные настройки | Десктоп |
| Директор | `director` | Весь учебный центр: филиалы, сотрудники, финансы, курсы, аналитика, интеграции | Десктоп |
| Администратор | `branch_admin` | Один филиал: ученики, группы, расписание, лиды, финансы, контроль | Десктоп |
| Учитель | `teacher` | Свои группы: посещаемость, оценки, ДЗ, квизы, свой доход | Десктоп |
| Помощник учителя | `support_teacher` | Группы привязанного учителя: посещаемость, оценки, задания | Десктоп |
| Ученик | `student` | Расписание, оценки, ДЗ, монеты, магазин, чат, профиль | **Мобайл-first** |
| Родитель | `parent` | Данные привязанных детей + чат с учителем | **Мобайл-first** |

## Навигация по ролям (сокращённо)

**branch_admin:** Панель/Сегодня · Ученики (Все / Заявки / Аккаунты / Тесты) · Группы (Группы / Расписание) · Финансы/Общее · Отчёты (Дневной / Аналитика) · Геймификация/Coins · Контроль (Нaзorat / Уведомления / Сообщения)

**director:** Панель · Ученики (по всем филиалам) · Сотрудники (Xodimlar / Зарплаты / Штрафы) · Курсы (Kurslar) · Финансы (Moliya) · Coins · Отчёты · Настройки (Филиалы / Интеграции / Общие / Уведомления / Аудит) · Связь/Сообщения

**teacher:** Панель/Сегодня · Обучение (Мои группы / Посещаемость / ДЗ / Оценки / Квизы) · Финансы/Мой доход · Связь/Сообщения

**student (мобайл):** Главная · Расписание · Оценки · ДЗ · Монеты · Профиль · Сообщения

**parent (мобайл):** Дети · Профиль · Сообщения

**superadmin:** Главная (все центры) · Аналитика платформы · Логи · Глобальные настройки

## Обязательное правило для агентов
Любое изменение экрана или эндпоинта проверяется по **всем 7 ролям**. В спеке фичи должна быть таблица «роль → что меняется / не меняется». Отсутствие таблицы = задача не готова.

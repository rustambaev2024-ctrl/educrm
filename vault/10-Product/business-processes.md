# Бизнес-процессы

## 1. Жизненный цикл ученика
Лид (заявка/звонок) → связь → пробный урок → конвертация в ученика (создание аккаунта) → запись в группу → посещение → оценки и ДЗ → оплата → сертификат/выпуск.

**Статусы ученика:** `active` · `frozen` (перерыв) · `debtor` (задолженность) · `archived` (завершил без сертификата) · `graduate` (сертификат) · `expelled` (отчислен).
При переходе в `expelled`/`archived`/`graduate` **автоматически закрываются все активные членства в группах**.

**Привязка родителя:** 6-значный код, живёт 24 часа.

## 2. Финансовый цикл
Пополнение кошелька → автоматическое списание за каждый проведённый урок (Celery-задача `daily_lesson_charge`) → при отрицательном балансе ученик получает статус `debtor` → зарплата учителя: `fixed_salary` либо `salary_percent` от оплат учеников его групп.

**Типы платежей:** `top_up` · `charge` · `manual_charge` · `manual_top_up` · `discount` · `refund` · `expense`.
Каждый платёж фиксирует `balance_before` и `balance_after`. **Это аудит-тропа — неприкосновенна.**

## 3. Проведение урока
Урок создаётся автоматически по расписанию группы → учитель открывает Davomat, выбирает урок (фильтр по дате, по умолчанию сегодня) → отмечает присутствие → Saqlash → монеты начисляются автоматически → списание за урок уходит в Celery.

## 4. Онбординг нового учебного центра
Суперадмин создаёт тенант (Institution: название, slug, настройки) → автоматически создаётся изолированная схема PostgreSQL → bootstrap (директор, филиал, ролевые пользователи) → директор настраивает курсы/группы/расписания/интеграции → администраторы начинают принимать учеников.

## Воронка лидов
`Yangi` (Новый) → `Aloqa qilindi` (Связались) → `Sinov darsi` (Пробный урок) → `Yozildi` (Записался) → `Rad etdi` (Отказался).
Источники: Walk-in · Phone · Telegram · Instagram · Referral · Other.
Перетаскивание карточки меняет статус. `Sinov darsi` открывает диалог назначения пробного урока. `Yozildi` открывает форму конвертации в ученика. Просроченный следующий контакт помечается оранжевыми часами.

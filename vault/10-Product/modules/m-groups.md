# Модуль: Курсы и группы
**Курс** — шаблон программы (название + описание), к нему привязано много групп.
**Группа** — конкретный класс: курс, филиал, кабинет, учитель, расписание, цена.

| Поле | Значение |
|---|---|
| Статус | `recruiting` → `active` → `frozen`/`completed` |
| Расписание | JSON: дни недели + время (напр. Пн/Ср/Пт 14:00) |
| Ёмкость | по умолчанию 15 |
| Цена | ежемесячная стоимость |

**Членство (`GroupMembership`)**: при выходе фиксируется `left_at`.
**Уникальное ограничение:** один ученик не может быть дважды **активным** членом одной группы.

**Легко сломать:** изменение расписания группы влияет на генерацию будущих уроков — нужно решить, что делать с уже созданными.

# Модуль: Геймификация (Coins)
Монеты, XP, уровни, достижения, магазин призов.

| Событие | Монеты (по умолчанию) |
|---|---|
| Присутствие на уроке | 10 |
| Опоздание | 5 |
| Отличная оценка (100) | 20 |
| Хорошая оценка (80+) | 10 |
| Сдача ДЗ | 15 |
| Правильный ответ в квизе | 5 |
| Стрик 7 дней | 50 |
| Стрик 30 дней | 200 |

Всё конфигурируется через `CoinSetting` (монеты за события, штрафы, XP-курс, уровни, расписание магазина).

**Уровни:** Boshlovchi (0 XP) → O'rta (500) → Yaxshi (1500) → A'lo (3000) → Champion (6000). **XP = 3 × монета**, начисляется автоматически.

**Магазин:** `Product` в `ProductCategory`. Ограничения: лимит покупок в неделю/месяц, минимальный уровень, дни работы магазина. Заказ: `new` → `confirmed` → `delivered` / `cancelled`.

**Достижения:** стрик дней, общие монеты, посещаемость, оценки, ДЗ, победы в квизах, достижение уровня.

**Легко сломать:** значения монет **нельзя хардкодить** — только из `CoinSetting`.

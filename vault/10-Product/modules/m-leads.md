# Модуль: Лиды (Murojaatlar)
Канбан-доска потенциальных учеников, 5 колонок: Yangi → Aloqa qilindi → Sinov darsi → Yozildi → Rad etdi.

**Карточка показывает:** имя, телефон, интересующий курс, источник, дату следующего контакта.
**Источники:** Walk-in, Phone, Telegram, Instagram, Referral, Other.

**Инварианты**
- Drag-and-drop меняет статус атомарно; при сбое API карточка возвращается на место (оптимистичный откат).
- `Sinov darsi` → диалог назначения пробного урока (дата, время, группа).
- `Yozildi` / кнопка `O'quvchi yaratish` → форма конвертации лида в ученика с созданием аккаунта.
- Просроченный next-contact → оранжевая иконка часов.

**Легко сломать:** конвертация лида создаёт пользователя — при повторном нажатии возможен дубликат аккаунта. Нужна идемпотентность.

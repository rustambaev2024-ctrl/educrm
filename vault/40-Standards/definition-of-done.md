# Definition of Done

> Задача **не переходит** на следующий этап, пока не выполнен DoD своего этапа.
> Проверяет `auditor` (Наzorat). Закрытая задача без DoD — нарушение процесса, а не «мелочь».

## DoD: Design
- [ ] Спека в `60-State/features/<id>-design.md`
- [ ] Таблица «роль → что меняется» по всем 7 ролям
- [ ] Только токены из [[design-system]], без новых цветов
- [ ] Все 5 состояний элементов + empty/loading/error экрана
- [ ] Таблица строк `ключ | UZ | RU`
- [ ] Мобайл-секция, если затронуты student/parent
- [ ] Явный список «что НЕ меняем»

## DoD: Dev (backend)
- [ ] Все ORM-запросы tenant-aware; Celery-задачи явно ставят схему
- [ ] Валидация в сериализаторах, а не во вьюхах
- [ ] Ошибки в формате `{detail:{uz,ru}}`
- [ ] Тесты: happy path + права по роли + изоляция тенантов
- [ ] Миграция обратима, применяется к shared и tenant-схемам
- [ ] `api-map.md` обновлён, если менялись эндпоинты
- [ ] Нет секретов в коде

## DoD: Dev (frontend)
- [ ] TypeScript без `any` в новом коде
- [ ] Никаких hex-цветов — только токены
- [ ] Иконки только `lucide-react`
- [ ] Опасные действия через `ConfirmDialog`
- [ ] Все 5 состояний реализованы
- [ ] Empty/loading/error состояния экрана
- [ ] Toast на каждое мутирующее действие
- [ ] Каждая строка есть на UZ и RU
- [ ] Мобайл-вёрстка через `MobileLayout` для student/parent
- [ ] Проверено под каждой затронутой ролью

## DoD: Code review
- [ ] Diff прочитан целиком, а не по заголовкам
- [ ] Нет ломающих изменений контракта API
- [ ] Стандарты слоя соблюдены
- [ ] Обратная совместимость данных

## DoD: Staging
- [ ] Ветка `staging` задеплоена, коммит зафиксирован в `state.json`
- [ ] Миграции применены без ошибок
- [ ] Celery worker и beat живы, Redis и MinIO отвечают
- [ ] Приложение поднялось (Daphne health)

## DoD: QA
- [ ] Тест-план покрывает **все** затронутые роли
- [ ] Регресс критических путей: посещаемость → монеты → списание, конвертация лида, зарплата
- [ ] Изоляция тенантов проверена на 2 тенантах
- [ ] UZ и RU проверены
- [ ] Мобайл проверен, если затронут
- [ ] Найденные баги оформлены как задачи со ссылкой на исходную

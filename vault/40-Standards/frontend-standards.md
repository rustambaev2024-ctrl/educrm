# Стандарты Frontend

**Стек (по факту `package.json`):** React 19.2 · TypeScript · TanStack Router 1.168 + TanStack Start 1.167 · Tailwind CSS **v4.2** · Vite 7.3 · Radix UI + shadcn/ui (`new-york`) · `lucide-react` · `sonner`

Читай обязательно: [[design-system]] · [[ui-principles]] · [[i18n]] · [[roles-permissions]]

## Как читать этот стандарт
Часть правил в проекте пока нарушается — это накопленный долг, зафиксированный в `vault/40-Standards/baseline.json`.
Правило действует так: **в новом и изменённом коде — соблюдать; существующее — не ухудшать.**
`scripts/baseline.py check` падает только при **росте** нарушений. Чинишь попутно — baseline опускается и обратно уже не поднимется.

Это сознательное решение: правило, нарушенное 145 раз, перестают читать вообще.

## Жёсткие правила
1. **Цвета.** **Любой hex в JSX — нарушение**, включая `#0077b6` / `#00b4d8` / `#1a2332` / `#f8fafc`: палитра переведена на изумрудную (`--brand` = `#059669`), синие значения — остаток старого бренда, а не «конвенция проекта». Только семантические токены и CSS-переменные, см. [[design-system]]. _Текущий долг: 76 вхождений небрендовых hex._
   <!-- Исправлено 2026-07-31 (T-004): прежняя редакция разрешала синие hex, что прямо противоречило design-system.md после его переписывания 2026-07-28. -->

2. **`ConfirmDialog`, никогда `window.confirm`.** _Текущий долг: 1._
3. **Иконки только `lucide-react`.** Emoji в UI запрещены. _Нулевая терпимость — 0 нарушений, так и держим._
4. **`any` — не добавлять.** _Текущий долг: 145. В новом коде — ноль._
5. **`gap-*` вместо `space-y-*`, `size-*` вместо `w-* h-*`.**
6. **Светлая и тёмная тема** — обе поддерживаются, [[ADR-001-dark-theme]] (accepted). Экран обязан быть корректен в обеих: не хардкодь `bg-white` / `text-gray-*` / светлые hex, пиши через токены. Тоггл — в `Topbar`, ключ `growbase.theme`.
   <!-- Исправлено 2026-07-31 (T-004): было «Только светлая тема» — устарело с принятием ADR-001. -->
7. Анимации 150–300 мс, уважать `prefers-reduced-motion`. Анимации shadcn Dialog/Sheet использовать как есть.
8. Строки — из i18n-словаря, каждый ключ имеет UZ и RU. Никогда не хардкодить в JSX.

## Каждый экран обязан иметь
- **Loading** — скелетон или «Сохраняем…», не спиннер на весь экран
- **Empty** — компонент `Empty`: иконка + понятный текст («У вас пока нет студентов») + кнопка действия. Никогда белый экран
- **Error** — `sonner` toast с конкретной причиной через `apiErrorMessage`. Не «Xatolik»
- **Toast на каждое мутирующее действие** — зелёный «Сохранено» или красный с причиной

## Каждый интерактивный элемент — 5 состояний
default · hover · active · disabled · loading

## Детали (столп 6)
Аватар с инициалами — цвет детерминирован по имени · иконки выровнены с текстом (`data-icon`) · чередование строк таблицы · тонкая цветная черта слева у активного пункта меню.

## Мобайл (столп 8)
Не сжатый десктоп. На мобиле: таблица → карточки, боковое меню → нижняя навигация, тач-таргеты **≥44px**, модалки снизу как `Drawer`/`Sheet`.
Порталы `src/routes/student/` и `src/routes/parent/` — **mobile-first через `MobileLayout`**.

## Роли и роутинг
Порталы в `src/routes/`: `superadmin` · `director` · `admin` (это портал роли **`branch_admin`** — имя папки историческое) · `teacher` · `support-teacher` · `student` · `parent`.
Экран работает под каждой ролью, которой доступен. Права — не «спрятать кнопку», а не рендерить блок. Проверка прав на бэкенде обязательна, фронт — только UX.

## Данные
- Все API-вызовы через `src/lib/api.ts`
- Ошибки приходят как `{detail:{uz,ru}}` — показывать по текущей локали
- Access-токен обновляется автоматически, не выкидывать пользователя при истечении
- Оптимистичные обновления (drag-and-drop лидов) **обязаны откатываться** при ошибке
